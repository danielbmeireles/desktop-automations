A collection of shell scripts to automate a bunch of little stuff on my Linux desktops.

## Why not Ansible?

Because I started these before I knew Ansible existed, and I don't want to rewrite the codebase just for the sake of it. Also, I don't need the full power of Ansible for this, and I prefer the simplicity of shell scripts for these kinds of tasks.
